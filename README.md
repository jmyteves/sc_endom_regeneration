# sc_endom_regeneration

Code and input tables for the figures of *Mapping Uterine Remodeling from Pregnancy to
a New Homeostatic State* (Teves et al.): a whole-uterus scRNA-seq time course in the
mouse (Control, E16.5, PPD1, PPD7, PPD30; 698,631 cells, 17,987 genes, 15 libraries)
with histology, morphometry and endometrial organoid assays.


## Layout

```
data/raw_light/      input tables and images; MANIFEST.csv gives origin, size, sha256
  fig1/              section morphometry (Fig. 1 F-H)
  liana/             LIANA output, epithelium as target (Fig. 5 B-C, Fig. 6 A-B)
  organoids/         tracked organoid diameters, representative wells, well images
  fig5_k5/, fig6/, sfig1-5/   tables of the earlier figure versions
data/staged/         four files from the atlas (scripts/00_stage_inputs.py) and the 139-gene
                     marker matrix from pseudobulk (scripts/stage_marker_deck139.py)
src/figN_panels.py   one module per main figure, build(repo_root, out_dir) -> {panel: path}
src/sfigN_panels.py  one module per supplementary figure, same contract
src/*_panels.py      the builders the figure modules call (see docs/PANEL_MAP.md)
scripts/             atlas staging, table builder, notebook generator
notebooks/           the two notebooks, generated by scripts/build_notebooks.py
docs/                PANEL_MAP.md (panel -> module -> inputs -> file), INPUTS.md
figures/             output (not tracked)
```



## Conventions

The fifth whole-tissue program is displayed as "New Homeostasis". `MODULES_summary.csv`,
`Fig3_module_genes.csv` and `Fig4_module_gene_assignment.csv` keep `Remodelling` as the
key; the rename happens at display time through `disp()` in each module. The cell type
`Stromal (remodeling)` is unrelated.

The per-compartment k = 5 modules of Fig. 4 B-E are a separate clustering from the five
whole-tissue programs of Fig. 3; their counts are not comparable.

Composition bars (Fig. 2 F) scale each cell type to its own maximum because cells per
stage span nineteenfold.

## Extras

`src/extras_panels.py` builds the panels of earlier figure versions that are not in the
current set (prefix `extra_`): the 16-type signalling composite, the DEG swarm matrix,
the dominant-program UMAPs, the depth and coverage controls and the coordination
analysis. They are listed in `docs/PANEL_MAP.md`.
